🎧 Podcast #12: Giới thiệu bản thân bằng tiếng Nhật

📅 2026-06-27 ⏱️ 15 phút 🏷️ N5 Level

Trong tập podcast hôm nay, chúng ta sẽ học cách giới thiệu bản thân bằng tiếng Nhật. Dưới đây là transcript đầy đủ với furigana tự động:

📄 トランスクリプト / Transcript

春樹: 皆さん、こんにちは。春樹です。

結衣: こんにちは！結衣です。

春樹: 今日は「自己紹介」について話しましょう。

結衣: いいですね！日本語の自己紹介は大切ですよね。

春樹: まず、基本的な表現から始めましょう。

結衣: はい。「はじめまして」は一番大事な挨拶ですね。

春樹: そうですね。次に名前を言います。「私の名前は春樹です。」

結衣: 「私は結衣と申します。」もう少し丁寧な言い方ですね。

春樹: 出身地も紹介しましょう。「東京から来ました。」

結衣: 「大阪出身です。」短い言い方もありますよ。

春樹: 趣味についても話せると良いですね。

結衣: 「趣味は音楽を聴くことです。」

春樹: 「私は読書が好きです。」

結衣: 仕事の紹介も大切です。「会社員です。」

春樹: 「学生です。大学で日本語を勉強しています。」

結衣: 最後に「よろしくお願いします」で締めくくりましょう。

春樹: 皆さんも練習してみてくださいね！

結衣: それでは、また来週！さようなら！

🔧 Cách nhúng vào Blogger

Thêm đoạn code sau vào phần <head> hoặc cuối <body> trong template Blogger:

<!-- Furigana for Blogger - CSS --> <link rel="stylesheet" href="furigana-blogger.css"> <!-- Dependencies (Kuroshiro + Kuromoji) --> <script src="https://cdn.jsdelivr.net/npm/kuroshiro@1.2.0/dist/kuroshiro.min.js"></script> <script src="https://cdn.jsdelivr.net/npm/kuroshiro-analyzer-kuromoji@1.1.0/dist/kuroshiro-analyzer-kuromoji.min.js"></script> <!-- Furigana for Blogger - JS --> <script src="furigana-blogger.js"></script>

⚙️ Tùy chỉnh cấu hình

Thêm thuộc tính data-furigana-config vào script tag, hoặc gọi API:

// Cách 1: Tắt auto-init, gọi thủ công FuriganaBlogger.init({ selector: '.transcript-content p.zh', showToggle: true, showLoading: true, animateOnLoad: true, }); // Cách 2: Bật/tắt furigana FuriganaBlogger.toggle(); // Cách 3: Xử lý lại khi DOM thay đổi FuriganaBlogger.reprocess();
